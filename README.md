# Conversor de Temperaturas en C

## Descripción

Este proyecto es una aplicación de consola desarrollada en lenguaje C que permite convertir temperaturas entre Celsius, Fahrenheit y Kelvin.

## Funcionalidades

- Celsius a Fahrenheit.
- Fahrenheit a Celsius.
- Celsius a Kelvin.
- Kelvin a Celsius.
- Fahrenheit a Kelvin.
- Kelvin a Fahrenheit.

## Tecnologías utilizadas

- Lenguaje C.
- GCC (compilador).
- Terminal de Windows o Linux.

## Compilación y ejecución

Compila el programa utilizando GCC:

```bash
gcc conversor.c -o conversor
```

Ejecuta el programa en Windows:

```powershell
.\conversor.exe
```

En Linux:

```bash
./conversor
```
